# InvestIQ - Investment & Risk Dashboard

## Overview
InvestIQ is a professional investment and risk analytics dashboard designed for fund of funds and wealth management portfolios. It provides comprehensive capabilities for performance measurement, advanced risk analysis, and robust stress testing. The platform aims to be an indispensable tool for financial professionals by integrating portfolio management, AI-powered document analysis, and sophisticated simulation tools, thereby enhancing decision-making and optimizing investment strategies.

## System Architecture
InvestIQ employs a modern full-stack architecture. The frontend is built with React 18 and TypeScript, utilizing Shadcn/ui components, Tailwind CSS for styling, and Recharts for data visualization. Routing is managed by Wouter and data fetching with TanStack Query. The backend is an Express.js application, also written in TypeScript, interacting with a PostgreSQL database via Drizzle ORM. Authentication is handled using Passport.js with a local strategy, session-based authentication, and scrypt for password hashing. The project uses Vite for building.

Key architectural features include:
- **Modular Frontend**: Components are organized by feature and reusability, with dedicated pages for various functionalities like Dashboard, Portfolio, Performance, Risk, Stress Tests, and custom tools.
- **Robust Backend Services**: Separated concerns for authentication, database interaction, file parsing, AI memo generation, and integrations (OneDrive, Gmail).
- **Comprehensive Data Model**: A detailed PostgreSQL schema supports portfolios, holdings, performance history, risk metrics, stress tests, AI-generated memos, custom portfolios, backtest results, a strategy library, and benchmarks, including custom composite benchmarks.
- **Advanced Analytics Engine**: Includes a Monte Carlo simulation engine for portfolio backtesting with bootstrap sampling and a portfolio optimizer supporting goals like Maximum Return, Maximum Sharpe Ratio, and Maximum Convexity.
- **AI Integration**: OpenAI GPT-5.2 is used for generating professional investment memos from uploaded documents, offering "Institutional Summary", "Everest Investment Summary", and "Verita Investment Memo" templates with rich formatting.
- **UI/UX Design**: A professional financial theme is applied, defaulting to dark mode, with a cyan/blue accent for primary actions, green for positive indicators, and red for negative. A dark sidebar complements a light content area.
- **Automatic Data Lookup**: Integration with Alpha Vantage API for automatic fetching of investment names, expected returns, and volatility based on ticker symbols.
- **Analytics Glossary**: Provides definitions, formulas, and interpretations for all financial metrics presented on the dashboard.

## External Dependencies
- **OpenAI GPT-5.2**: Used for AI-powered investment memo generation.
- **Microsoft Graph API**: Integrated for OneDrive file access and import capabilities.
- **Google APIs**: Utilized for Gmail integration (listing messages, reading emails, sending emails, searching, and label management).
- **PostgreSQL**: Primary database for all application data.
- **Alpha Vantage API**: Used for real-time market data lookup, specifically for investment names, expected returns, and volatility based on ticker symbols.
- **FRED API**: Integrated for fetching the 3-month Treasury bill rate (DTB3 series), with a 24-hour caching mechanism. Used as the default risk-free rate for Sharpe ratio calculations in Monte Carlo simulations.

Searches 5 data sources simultaneously (SEC EDGAR Filing Search, SEC EDGAR Full-Text, Alpha Vantage, OpenFIGI, Known Universe database). Results are automatically cross-referenced and reconciled with a confidence score. The reconciliation engine uses source priority rankings (SEC EDGAR highest, then Alpha Vantage, Known Universe, OpenFIGI) to resolve data conflicts. Users can view field-by-field verification, data conflicts and resolutions, and raw source data before importing reconciled funds into their local database. Implementation in `server/intervalFundSources.ts` with routes at `/api/interval-funds-universe/search` and `/api/interval-funds-universe/import`. Frontend "Universe Search" tab on the Interval Funds page.

Implementation in `server/benchmarkDataService.ts` with auto-refresh on first access and manual refresh via POST `/api/benchmarks/:id/refresh`. Benchmark selections are managed client-side via localStorage (per portfolio), eliminating the FK constraint issue with the `portfolioBenchmarks` table. The "Import from File" tab provides drag-and-drop file upload (PDF, Excel, CSV) with automatic investment extraction, editable review table, and one-click custom portfolio creation from imported data. - **Fully Dynamic Analytics** (Feb 2026): ALL analytics across Dashboard, Risk Analytics, and Performance pages are now dynamically calculated from portfolio performance history, selected benchmark returns (via Alpha Vantage/stored data), and FRED-sourced risk-free rate. No seeded/static risk metrics are used. Dashboard benchmark overlay uses actual selected benchmark return data. Performance page alpha uses selected benchmark cumulative returns. New capabilities include: Cornish-Fisher VaR (skewness/kurtosis-adjusted), Parametric & Historical Expected Shortfall at 95%/99%, Modified Sharpe Ratio, Kurtosis-Adjusted Volatility, Conditional Drawdown at Risk (CDaR 95%), Drawdown Duration Analysis (max/avg duration, current drawdown), Component/Marginal Risk Contributions (Euler decomposition), Factor Risk Decomposition (systematic vs idiosyncratic via single-factor CAPM), Ledoit-Wolf Shrinkage Covariance Estimator, and Monte Carlo Stress Simulation (200 paths across 5 stress regimes). New API endpoint at `/api/risk/advanced` serves all advanced metrics. Risk Analytics page includes three new sections: Advanced Tail Risk & VaR Methodology, Factor Decomposition with PieChart, and Component Risk Contribution with progress bars. Monte Carlo stress scenarios also displayed on Risk page with summary statistics.
- **Monte Carlo Factor-Model Stress Testing** (Feb 2026): Stress Testing page now includes a Monte Carlo simulation section alongside the existing scenario-based stress tests. Users can run 200-path simulations across 5 stress regimes (Base Case, Mild Stress, Moderate Crisis, Severe Crisis, Black Swan) with progressively stressed mean returns and volatility multipliers. Results show simulated return path charts, return distribution percentiles, probability of loss, expected shortfall, and average max drawdown. API endpoint at `POST /api/stress-tests/monte-carlo`. Interactive scenario tabs allow switching between stress levels.
- **Frequency-Aware Charts & Labels** (Feb 2026): All analytics charts (Dashboard, Performance, Risk) now dynamically detect whether portfolio data is daily, weekly, monthly, or quarterly. Implementation in shared utility `client/src/lib/data-frequency.ts` with functions for frequency detection, period-appropriate formatting, and optimal tick interval calculation.
